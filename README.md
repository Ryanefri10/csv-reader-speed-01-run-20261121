csv-reader-speed-01: fast drop-in for csv-reader 1.0.0 (indexOf/slice parser, exact semantics). `run(input)` returns exactly csv-reader's `{columns, rows, errors}` for `{text, header}`, but parsed with indexOf/slice scanning instead of one character at a time. Pure stdlib, no dependencies — no clock, no randomness, nothing kept from one call to the next.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
